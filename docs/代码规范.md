# C++ 解答编写规范

## 文件与目录

每道题的 C++ 解答放在对应题目目录的 `main.cpp` 中，使用 G++ 提交。题面文件 `problem.md` 和 `problem.json` 保持原样。

```text
Experiment 1.1/
└── 18957 Derivative of Natural Logarithm ln(x)/
    ├── problem.md
    ├── problem.json
    └── main.cpp
```

## 头文件与命名空间

头文件限于 `iostream`、`algorithm`、`vector`、`string`、`set`、`stack`、`queue`、`array`、`map`、`cctype`、`cstdio`、`cstdlib`、`utility`、`iomanip`，按需包含。

包含头文件后使用 `using namespace std;`，调用函数时省略 `std::` 前缀。清单不包含 `cmath`。正弦、余弦、对数和指数题使用题目文件内的数值实现；黄金分割题使用 G++ 内建函数 `__builtin_exp`，无需额外头文件。

## 输入与输出

- 使用标准输入读取数据，按题目规定处理空白和多组输入。
- 输出只包含题目要求的结果，不打印提示语、调试信息或额外说明。
- 严格遵循题目指定的行数、小数位数、分隔符和空格格式。
- 不要假设样例展示的输入范围就是完整约束；实现以题面为准。

## 数值计算

- 根据题目指定的方法实现算法，并按题目要求设定迭代条件或误差界。
- 中间计算尽量保留浮点精度，只在题目要求时格式化或舍入输出。
- 检查题目定义域、边界值、零值以及可能影响收敛或稳定性的输入。
- 需要比较浮点结果时，使用与题目误差要求相符的判断方式。

## 本地运行

从仓库根目录运行对应文件，例如：

```powershell
g++ -std=c++11 -O2 "Experiment 1.1/18957 Derivative of Natural Logarithm ln(x)/main.cpp" -o main.exe
./main.exe
```
