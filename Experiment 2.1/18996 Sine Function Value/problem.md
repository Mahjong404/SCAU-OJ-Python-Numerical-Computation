# 18996 求正弦函数值

- 实验：数值计算实验2.1
- OJ 来源：[SCAU OJ](https://acm.scau.edu.cn/uoj8000/common_problem_view_PUBLIC.html?problemId=18996)

## Description

求正弦函数值，输入实数x(弧度，0到π) ，输出x对应的正弦函数值（使用双精度double类型精确到小数点后14位有效数）。

## 输入格式

m(整数，实验数据总数)
x1(弧度，0到π)
x2(弧度，0到π)
...
xm(弧度，0到π)

## 输出格式

实验输出数据格式
y1(实数，x1的正弦函数值)  
y2(实数，x2的正弦函数值)
...
ym(实数，xm的正弦函数值)

## 输入样例

3
0.0
0.5
1.0

## 输出样例

0.00000000000000
0.47942553860420
0.84147098480790
