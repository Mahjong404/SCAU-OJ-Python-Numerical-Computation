# 18957 计算自然对数ln(x)的导数

- 实验：数值计算实验1.1
- OJ 来源：[SCAU OJ](https://acm.scau.edu.cn/uoj8000/common_problem_view_PUBLIC.html?problemId=18957)

## Description

求自然对数ln(x)的导数，输入双精度实数x>=1，输出自然对数ln(x)的导数（精确到小数点后2位有效数，小数点后第2位四舍五入所得）。

## 输入格式

m(整数，实验数据总数)
x1(实数，自然对数ln(x)的自变量)
X2实数，自然对数ln(x)的自变量)
...
xm(实数，自然对数ln(x)的自变量)


## 输出格式

y1(实数，自然对数ln(x1)的导数)
y2实数，自然对数ln(x2)的导数)
...
ym(实数，自然对数ln(xm)的导数)


## 输入样例

3
1.0
2.0
3.0


## 输出样例

1.00
0.50
0.33
